# Ordering hardware

Ploos-AS hardware projects are vendor-neutral. You may download the released manufacturing package and order the board from any suitable PCB manufacturer.

See [MANUFACTURING.md](MANUFACTURING.md) for the manufacturing and qualification policy.

## Before ordering

Only order a PCB revision that has a qualified manufacturing release. Use the manufacturing ZIP attached to the matching GitHub Release rather than files from an arbitrary development commit.

Check the project's release notes for prototype status, known limitations, required assembly options, and any hardware-specific warnings before ordering.

## Use another manufacturer

You do not need to use any manufacturer listed above. Download the qualified manufacturing package from the matching GitHub Release and submit it to a manufacturer of your choice.

The project's hardware licence does not require use of a particular fabrication or assembly service.

## Affiliate, referral and sponsorship disclosure

Some future ordering links may be affiliate, referral, shared-project, or sponsored links. Ploos AS may receive commission, account credit, free prototypes, discounts, or another benefit if such a link is used.

Any link for which Ploos AS may receive a benefit must be identified as such next to the link. A commercial relationship does not make a manufacturer preferred, required, or exclusive, and does not change the open-hardware licence.

## Maintainer checklist

Before replacing a placeholder above with a direct ordering link:

- the exact PCB revision must have passed the repository manufacturing qualification;
- the manufacturer's project must correspond to that exact released revision;
- the release manufacturing ZIP must remain independently downloadable;
- the link must identify any affiliate/referral/sponsorship relationship;
- manufacturer-specific settings that affect correctness must be documented;
- the ordering page must not be described as the only way to obtain the hardware.

If a manufacturer project becomes stale or no longer matches the qualified release, remove or mark the link until it has been revalidated.
